# Split hotel payments: rooms, restaurant, and the night audit gap

Room paid. Restaurant half on mobile money. Minibar on a promise. Morning audit cannot tell the guest story. Split payments are normal. Split systems are the leak.

## Definition

**Split payment leak** is stay-related charges recorded in disconnected books so the folio never matches cash and wallets.

## What doing nothing already costs

| Leak | What you already pay |
|------|----------------------|
| Separate restaurant book | Missed charges |
| Mobile money without folio link | Unmatched deposits |
| Verbal comps | Margin holes |
| Late posting | Angry checkout |

Escape, not shame: staff improvising were the system. Give them a calmer one.

## Framework

1. Post all outlets to the stay folio where possible
2. Tag payment method and reference
3. Run night audit from one system
4. Limit comps with roles
5. Reconcile wallets to folios daily

## Believable operational scenario

A guest disputes breakfast charges already paid on Orange Money. The restaurant notebook and the room folio disagree. Ten minutes becomes an hour.

## Common mistakes

- Outlet islands
- Comps without logs
- Ignoring restaurant in owner dashboards



## Tools that help

Unified folio, payment methods, role for restaurant lead, owner visibility.


## Checklist

- [ ] Loss written as one dated sentence
- [ ] Object and ID defined
- [ ] Capture and review roles named
- [ ] Two-week parallel run
- [ ] Success = time or disputes, not logins

## Fourteen-day path

Date the loss, define the object, capture new events, compare disputes, retire the shadow process for pilot scope. Simplify if calm does not improve.

## Why this leak compounds weekly

Improvisations multiply. New staff learn workarounds. Calm surfaces hide disputes until reconstruction is forced.

## What good looks like after two weeks

Faster capture, mid-week review, leave-safe records, leadership answers without calling three people.

## Metrics that matter

Time to answer, disputes, exception age, close or report length. Ignore vanity logins.

## Kinshasa / Nairobi notes

Mobile money, WhatsApp front door, patchy signal. Localise labels; keep object discipline.

## How AI changes this

AI reminds and summarises. It does not invent proof. Design evidence rules first.
